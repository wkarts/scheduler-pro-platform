# Identidade visual — ARGWS Visual Builder 2.2

A identidade 2.2 usa os arquivos de marca fornecidos para o produto.

## Assinatura

- Nome: **ARGWS Visual Builder**
- Símbolo curto: **AVB**
- Posicionamento: Visual Builder universal e framework-agnostic.

## Paleta principal

- Cyan: `#19E8EF`
- Blue: `#0D82FF`
- Blue 600: `#1768F2`
- Violet: `#7B43FF`
- Navy: `#08172B`
- Navy deep: `#06101F`

Gradiente principal:

```css
linear-gradient(135deg,#19e8ef 0%,#0d82ff 50%,#7b43ff 100%)
```

## Aplicação no editor

- símbolo AVB real na toolbar;
- publicação/ações primárias usam gradiente da marca;
- tema dark usa navy profundo, não preto absoluto;
- tema light usa superfícies azul-cinza suaves;
- tipografia UI em peso 400/500; 600 apenas para hierarquia;
- scrollbars de baixo contraste.
