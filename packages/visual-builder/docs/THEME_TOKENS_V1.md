# Theme Tokens v1

O template entrega identidade sem injetar CSS arbitrário no painel do host.

```json
{
  "schema": "argws-theme-tokens/v1",
  "name": "Studio Beatriz",
  "colors": {
    "primary": "#c31f62",
    "secondary": "#2b2527",
    "accent": "#b5864e",
    "background": "#f8f6f3",
    "surface": "#ffffff",
    "text": "#332d2f"
  },
  "typography": {
    "heading": "Playfair Display, serif",
    "body": "Inter, sans-serif"
  }
}
```

Hosts podem mapear esses tokens para suas próprias variáveis (`--sp-primary`, `--erp-primary`, etc.).
