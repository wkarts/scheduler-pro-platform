# Favicon do Admin em tema escuro

O painel administrativo usa um favicon SVG exclusivo em branco sobre fundo transparente:

```text
apps/admin/public/favicon-dark.svg
```

A geometria segue o símbolo oficial do Scheduler PRO, mas sem o fundo azul, para manter contraste
adequado em navegadores e abas com tema escuro. O favicon colorido original permanece disponível
para as demais aplicações e para contextos claros.
