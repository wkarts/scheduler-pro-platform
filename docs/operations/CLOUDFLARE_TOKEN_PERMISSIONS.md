# Permissões do token Cloudflare

Para a operação padrão do Scheduler PRO:

- `Zone Read`: descobrir/validar a zone;
- `DNS Edit`: criar e consultar registros temporários e desafios DNS-01;
- `Cache Purge`: invalidar cache por hostname no painel.

Permissões de Custom Hostnames/SSL são adicionais e só se aplicam ao fluxo de domínio próprio via
Cloudflare for SaaS.
