# Admin — guia rápido do tenant

1. Entre no Control Plane.
2. Clique em **Gerenciar tenant** no canto inferior direito.
3. Escolha o cliente.
4. Edite nome/fuso em **Dados do tenant**.
5. Altere e-mail/nome/senha em **Usuário principal do tenant**.
6. Use **Suspender**, **Restaurar** ou **Excluir tenant** em **Ciclo de vida**.

A exclusão desse painel é lógica e preserva banco, storage e artefatos para restauração.
