# Scheduler Pro Desktop — aplicação modelo Tauri/Rust

Esta aplicação deve seguir o padrão do template `template-app-tauri-desktop-main` enviado para o projeto.

Mantido do template: Tauri 2, Rust, Vue 3, TypeScript, Pinia, Vue Router, startup/splash, configuração por runtime, preparação desktop e base para Android/iOS.

Desativado neste estágio: licenciamento, telemetria, serviço headless, webhook/websocket local e módulos técnicos que ainda não fazem parte do Scheduler Pro.

A aplicação web principal continua sendo o PWA em `apps/web`. Desktop e mobile usam esta base Tauri para gerar binários, APK/AAB e builds white-label pelo Build Manager.
