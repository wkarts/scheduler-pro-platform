# AVB Template Studio — material permanente do Control Plane

Este diretório é empacotado com a API para que o administrador tenha acesso remoto ao material oficial de construção de templates, mesmo sem sua máquina de desenvolvimento.

Conteúdo:
- padrão mestre para IA;
- documentação do Template Runtime SDK v1;
- Experience Contract v2;
- Bindings v1;
- Theme Tokens v1;
- migração v1 → v2;
- exemplo enriquecido de Experience Package v2;
- pacote NPM/Universal do AVB 2.4.0 quando disponível.
